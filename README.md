# Velocity 3D

A high-quality browser racing prototype inspired by arcade track racers.

## Features
- Three selectable cars with different performance characteristics
- Live paint and wheel customization
- Aero/downforce and traction-control settings
- Procedural 3D circuit
- Dynamic chase camera
- PBR-style materials, shadows, fog and multiple light sources
- Trees, rocks, guardrails, road shoulders and start grid scenery
- Rival cars
- Keyboard driving: WASD / Arrow keys, Space handbrake, R reset
- Static deployment compatible with Vercel

## Run
Open `index.html` in a modern browser or deploy the repository to Vercel.
